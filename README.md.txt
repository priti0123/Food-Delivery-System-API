# 🍔 Food Delivery System

## 📌 Project Overview

The **Food Delivery System** is a web-based application developed using **Spring Boot** that allows users to browse restaurants, order food online, and manage deliveries efficiently. It simulates a real-world food ordering platform with admin and user functionalities.

---

## 🚀 Features

* 🔹 User registration and login
* 🔹 Browse restaurants and food items
* 🔹 Add items to cart
* 🔹 Place and track orders
* 🔹 Admin panel for managing restaurants and orders
* 🔹 Order history management

---

## 🛠️ Tech Stack

* **Backend:** Java, Spring Boot, Spring MVC
* **Frontend:** Thymeleaf, HTML, CSS
* **Database:** MySQL
* **Build Tool:** Maven
* **IDE:** Eclipse

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```id="4x5v9k"
git clone https://github.com/your-username/Food-Delivery-System.git
```

### 2️⃣ Open in IDE

* Import the project into Eclipse as a Maven Project

### 3️⃣ Configure Database

Update `application.properties`:

```id="w8h7pz"
spring.datasource.url=jdbc:mysql://localhost:3306/food_delivery_db
spring.datasource.username=root
spring.datasource.password=your_password
```

### 4️⃣ Run the Application

* Run the main Spring Boot class

### 5️⃣ Access the Application

```id="71nf9t"
http://localhost:8080
```
